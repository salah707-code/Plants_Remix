# موسوعة النباتات (Plant Encyclopedia)

تطبيق أندرويد متكامل ومبني باستخدام Kotlin و Jetpack Compose لتوثيق وتصنيف النباتات الطبية والعطرية والغذائية والتجميلية.

## المميزات الرئيسية
- **دليل نباتي شامل**: استعراض السجلات النباتية مع الأسماء العربية والإنجليزية والعلمية والفصائل والتصنيفات.
- **تفاصيل المواد الفعالة**: عرض المواد الكيميائية الطبيعية والخصائص الطبية والاستخدامات والملاحظات الموثقة.
- **بحث وتصفية ذكية**: فلترة سريعة حسب نوع الاستخدام (علاجية، غذائية، عطرية، تجميلية) وبحث فوري.
- **تصفح حسب الفصائل**: تقسيم النباتات وتصفحها وفقاً للفصائل النباتية.
- **المفضلة وحفظ السجلات**: إمكانية حفظ النباتات في المفضلة وتعديل بيانات وملاحظات النباتات محلياً مع قاعدة بيانات Room.
- **إضافة نباتات جديدة**: إمكانية توثيق نباتات جديدة وإضافتها إلى قاعدة البيانات.
- **واجهة مستخدم عصرية**: تصميم عصري وفق إرشادات Material Design 3 مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
